AI INTERVIEW AGENT — BUG LIST

1. QUESTION PROGRESS
- Question/progress bar gets stuck.
- Main question number does not reliably advance.
- Follow-up questions must NOT increment the main question number.
- Backend should be the single source of truth for progress.

2. INTERVIEW COMPLETION / FEEDBACK
- Interview does not reliably reach the completed state.
- Because completion is not triggered correctly, the Results/Feedback page is not reached.
- Verify the flow: Q1 → ... → Q8 → interview end → report → ResultsPage.

3. BAD FIRST QUESTION
- AI currently exposes raw curriculum titles as questions.
- Example: "Agentic Frameworks: LangChain Agents & Tool Use"
- Replace this with a professional greeting and introduction question.
- First question should feel like a real interviewer, not a curriculum label.

4. POOR AI QUESTION QUALITY
- Questions need to be more natural and context-aware.
- Weak answer → simpler follow-up on the same topic.
- Partial answer → probing follow-up.
- Good answer → deeper question.
- Excellent answer → harder question, then eventually move topic.
- LLM should generate wording; AdaptiveInterviewEngine should control interview progression.

5. CHAT AUTO-SCROLL
- Chat does not reliably stay on the newest message.
- New user/AI messages should automatically scroll to the bottom.
- Check the existing auto-scroll implementation before rewriting it.

6. STATE SYNCHRONIZATION
- Frontend and backend can disagree about question number/progress.
- Avoid calculating interview progression independently in React.
- Keep current question, topic, progress, remaining questions, and completion state synchronized from backend.

PRIORITY:
1. Fix question progression/state
2. Fix interview completion + feedback
3. Improve AI questions
4. Fix chat auto-scroll
5. Verify complete end-to-end interview flow
